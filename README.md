# Птицелов Remastered — GitHub Ready

Готовая браузерная игра для публикации через **GitHub Pages**.

## Что внутри
- `index.html` — вся игра в одном файле.
- `assets/images/` — изображения героев, локаций и птиц.
- Полностью автономная работа без сервера и базы данных.
- Сохранение прогресса через `localStorage`.
- Поддержка ПК и телефона.

## Управление
### ПК
- **WASD / стрелки** — движение героя
- **Пробел** — ловить птиц

### Телефон
- **Левый джойстик** — движение
- **Кнопка «Ловить»** — взмах сачком

## Как опубликовать на GitHub Pages
1. Распакуй архив.
2. Загрузи всё содержимое в корень репозитория `pticelov`.
3. В GitHub открой: **Settings → Pages**.
4. Выбери **Deploy from a branch**.
5. Branch: **main**.
6. Folder: **/(root)**.
7. Нажми **Save**.

Через 1–3 минуты игра будет доступна по ссылке вида:

`https://deringserega.github.io/pticelov/`
