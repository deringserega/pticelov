# Птицелов Infinity — GitHub Pages Ready

Обновлённая браузерная игра на Phaser 3.90.0.

## Главное
- 50 уровней: 5 глав × 10 уровней.
- Каждый 10-й уровень — босс Беркут.
- 15 птиц с фотореалистичными карточками.
- 4 героя с индивидуальными бонусами и собственным уровнем.
- Прогресс героя, общий уровень, экипировка и экономика.
- 7-дневная серия ежедневных наград.
- Ежедневные и недельные задания.
- 10 достижений.
- Сезон из 30 ступеней с наградами.
- Локальная офлайн-лига результатов.
- Адаптивная сложность: после серии промахов игра слегка помогает игроку, а редкая добыча имеет pity-механику.
- Музыка, пение птиц, звуки сачка, поимки, наград и босса.
- Мобильный интерфейс без длинной вертикальной прокрутки: нижняя навигация, горизонтальные свайп-карусели и полноэкранные карточки.
- WASD/стрелки + пробел на ПК, джойстик + кнопка «Ловить» на телефоне.
- PWA и кэш локальных ассетов через Service Worker.
- Сохранение прогресса в localStorage + ручной экспорт/импорт резервной копии.

## Публикация на GitHub Pages
1. Распакуй архив.
2. Замени содержимое репозитория `pticelov` файлами из архива.
3. GitHub Pages должен быть настроен на `main` → `/(root)`.
4. После Commit GitHub автоматически опубликует новую версию.

## Важно про интернет
Phaser 3.90.0 загружается с jsDelivr. Первый запуск должен быть с интернетом. Service Worker затем пытается сохранить загруженный ресурс в кэш браузера.

## Важно про облако и глобальный рейтинг
Эта версия работает на GitHub Pages без сервера, поэтому прогресс хранится локально. Встроены экспорт/импорт сохранения и офлайн-лига. Настоящее облачное сохранение между устройствами и реальный глобальный рейтинг требуют внешнего backend (например Supabase/Firebase) и ключей проекта.
