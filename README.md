# Птицелов Deluxe — Phaser Edition

Готовая браузерная игра для публикации через GitHub Pages.

## Главное

- Phaser 3.90.0 + WebGL/Canvas.
- Arcade Physics для героя и птиц.
- 4 героя с фотографиями и разными бонусами.
- 5 локаций с отдельной атмосферой и погодой.
- 8 видов птиц с фотореалистичными изображениями.
- WASD/стрелки + пробел на ПК.
- Виртуальный джойстик + кнопка «Ловить» на телефоне.
- Сачок с радиусом ловли и кулдауном.
- Птицы используют движение к цели, избегание героя, разделение стаи и столкновения с границами.
- Частицы, кольца поимки, floating text, camera shake, туман/снег/дождь/пыльца.
- Комбо, редкость, опыт, уровни, магазин, квесты и коллекция.
- Процедурные звуки через Web Audio API — отдельные аудиофайлы не нужны.
- Прогресс сохраняется в localStorage.
- PWA manifest + service worker: после публикации игру можно добавить на главный экран телефона.

## Файлы

- `index.html` — интерфейс и подключение Phaser.
- `style.css` — весь интерфейс и адаптивная верстка.
- `game.js` — логика, Phaser-сцена, физика, экономика и звук.
- `manifest.webmanifest` — режим приложения на смартфоне.
- `sw.js` — кэширование ресурсов.
- `assets/images/` — герои, птицы и локации.
- `assets/icons/` — иконки приложения.

## Публикация на GitHub Pages

1. Удали/замени старые файлы в репозитории `pticelov`.
2. Загрузи содержимое этого архива прямо в корень репозитория.
3. GitHub → **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: **main**.
6. Folder: **/(root)**.
7. Save.

Ссылка будет вида:

`https://deringserega.github.io/pticelov/`

## Важно

Phaser 3.90.0 подключается через официальный CDN jsDelivr. Поэтому при первом открытии игры нужен интернет. После первого запуска service worker кэширует загружаемые ресурсы браузера, где это разрешено.

## Управление

### ПК
- WASD / стрелки — движение.
- Пробел — взмах сачком.

### Телефон
- Джойстик слева — движение.
- Кнопка «Ловить» справа — сачок.
- Кнопка «Приманка» — повышенный шанс редких птиц на 9 секунд.
